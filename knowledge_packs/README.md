# Knowledge Packs (published collection)

This directory is the published pack collection: the Save Editor's
"Download Knowledge Packs" button fetches these files from GitHub at
runtime (`.json` files only).

The copy bundled inside the application lives in
`CrimsonSaveEditor/knowledge_packs/` — it ships with the one default
pack the Call Dragon repair workflow requires, and downloaded packs are
stored there next to the executable. Add new community packs here.
