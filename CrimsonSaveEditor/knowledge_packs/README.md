# Knowledge Packs (bundled + runtime)

Packs in this directory are bundled into the Save Editor executable and
this is also where the in-app downloader stores packs at runtime.

It intentionally ships with only the default pack required by the Call
Dragon repair workflow ("No Map Reveal Abyss Gate Unlock Only.json").
The full published collection lives at the repository root in
`knowledge_packs/` and is fetched on demand by the "Download Knowledge
Packs" button.
